# MoneyBeetle 요구사항 명세서

## 1. 개요

MoneyBeetle은 2030 사회초년생이 내 집 마련에 필요한 금융 지식을 영상 강의와 퀴즈로 배우고, 가상 캐시로 투자와 청약을 연습하는 웹 학습 플랫폼입니다.

**목적:** 자본(월급 관리·예적금·주식·ETF)과 부동산(청약·전월세·대출) 지식을 “내 집 마련”이라는 하나의 목표 아래 배우고, 실제 돈을 쓰기 전에 안전하게 연습하게 합니다.

**범위:** 영상 강의와 퀴즈, 오답노트·스크랩, 오늘의 경제 용어, 출석·경험치·캐시, 시즌제 모의투자, 모의 청약, 강사 기능, 관리자 백오피스. 실제 금융 거래·실제 청약 신청·실시간 시세 연동은 범위에서 제외합니다.

**저장소:** github.com/bukkeu/MY-HOME

### 용어 정의

| 용어 | 정의 |
| --- | --- |
| 카테고리 / 소주제 / 강의 | 최상위 학습 분류(자본, 부동산) / 카테고리 하위 분류(예: 월급 관리, 예적금, 주식, 청약, 전·월세, 대출) / 강사가 올린 학습 묶음. 한 강의에는 영상 최대 3개와 요약글, 퀴즈가 들어간다. |
| 테스트 퀴즈 / 퀴즈 | 영상 시청 전에 푸는 OX 5문제(불이익 없음) / 영상 시청 후 푸는 4지선다 10문제(±5). 퀴즈를 통과하면 학습 완료가 된다. |
| 오답노트 | 퀴즈에서 틀린 문제를 모아 둔 곳. 다시 풀 수 있다. |
| 경험치(XP) / 레벨 / 칭호 | 학습 활동으로 쌓이는 점수 / 그에 따른 단계 / 레벨 구간별 이름(텐트 → 원룸 → 투룸 → 아파트 → 내 집) |
| 캐시 | 출석, 학습 완료, 레벨업으로 쌓는 서비스 안의 가상 재화. 모의투자 투자 가능 금액과 청약통장 납입에 쓰인다. (기획 메모의 “게임머니”와 같은 뜻) |
| 해금 / 블러 | 레벨 조건을 채워 트레이닝 기능이 열리는 것 / 조건 미달일 때 메뉴를 흐리게 가리고 필요한 레벨을 안내하는 표시 |
| 시즌 / 턴 / 휴장 | 모의투자의 운영 기간(14일) / 시즌 안에서 시장이 한 단계 진행되는 단위(하루 1턴, 총 12턴) / 일요일(턴 없음) |
| 투자 가능 금액 | 시즌 참가 때 받는 금액 = 모은 캐시 + 이월금 |
| 이월금 | 지난 시즌 수익의 일부(비율과 상한은 관리자가 설정)를 다음 시즌 투자 가능 금액에 더하는 금액 |
| 청약통장 / 납입회차 | 회원가입과 동시에 만들어지는 가상 통장 / 하루에 한 번 납입할 때마다 늘어나는 횟수. 가점과 당첨 산정에 쓰인다. |
| 가상 단지 | 모의 청약용으로 관리자가 등록한 가상의 아파트 단지 |

## 2. 사용자 및 권한

사용자는 비회원, 회원(학습자), 강사, 관리자 네 종류이며, 회원의 트레이닝(모의투자·모의 청약)은 레벨에 따라 열립니다.

| 구분 | 설명 | 주요 권한 |
| --- | --- | --- |
| 비회원 | 로그인하지 않은 방문자 | 서비스 소개, 회원가입, 로그인 |
| 회원 | 2030 사회초년생 학습자 | 강의 시청, 테스트 퀴즈·퀴즈, 오답노트·스크랩, 강의 문의, 출석·캐시, 해금된 모의투자·모의 청약 |
| 강사 | 강의를 만드는 사람 | 강의·영상·요약글·퀴즈 등록, 검수 요청, 내 강의 문의 답변 |
| 관리자 | 서비스 운영자 | 카테고리·강의 검수, 경제 용어, 회원·강사, 문의 게시판, 모의투자 시즌 운영, 모의 청약 운영 |

기능은 9개 영역, 총 120개 요구사항으로 나눕니다. 우선순위는 상(필수 구현) 77개, 중(가능하면 구현) 33개, 하(시간이 남으면 구현) 10개입니다.

## 5. 제약사항 및 확인 필요 사항

### 제약사항 및 가정

- 모든 시세, 뉴스, 기업정보, 단지 정보는 관리자가 등록한 가상 데이터이며 실시간 시세 등 외부 API와 연동하지 않는다.
- 실제 결제, 실제 금융 계좌 연결, 실제 청약 신청 기능은 제공하지 않는다.
- 청약 가점 계산은 학습용으로 단순화하며, 실제 제도와 다를 수 있음을 화면에 안내한다.
- 간편 로그인(구글·카카오)과 본인인증은 외부 서비스 연동이 필요해 우선순위를 하로 두었다. 연동 대신 가상 화면으로 대체할지 팀에서 정한다.

## 6. 이전 명세서에서 빠지거나 바뀐 것

최종 기획 메모에 없어서 이번 명세서에서 뺀 항목입니다. 다시 넣을 항목이 있으면 알려 주세요.
